## O que é Análise de Complexidade de Espaço?

- É a estimativa de espaço de memória principal necessário para executar um algoritmo
   **Complexidade espacial de um algoritmo:**
			**- Espaço necessário pra armazenar o código-fonte (Constante)**
			**- Espaço necessário para variáveis simples (Constante)**
			**- Espaço necessário para as estruturas de dados usadas (Variável)**
			**- Espaço necessário para pilha de recursão de algoritmos recursivos (Variável)**

## O que é Análise de Complexidade de Tempo?

- É a estimativa de computações da CPU (processos) necessários para executar um algoritmo
   **Complexidade temporal de um algoritmo:**
			**- Soma da contagem de frequência de cada instrução de um algoritmo (Número de vezes que a instrução é executada)
