
## Algoritmos x Códigos

| Algoritmos                                               | Códigos                                              |
| -------------------------------------------------------- | ---------------------------------------------------- |
| É o Design (Um passo-a-passo)                            | É a Implementação (A execução do design)             |
| Nível de Conhecimento (Engenheiros e Arquitetos)         | Nível Técnico (Programador)                          |
| Podem existir em qualquer língua                         | Existe apenas em linguagens de programação           |
| Não dependem de Hardware, Software e Sistema Operacional | Dependem de Hardware, Software e Sistema Operacional |
| É analisado                                              | É testado                                            |
| Tamanho (espaço) medido em palavras                      | Tamanho (espaço) medido em byte                      |
| Tempo em Unidades de Tempo (UT)                          | Tempo em segundos                                    |
|                                                          |                                                      |
## Diferenciais e critérios

- Tempo
- Espaço
- Carga e Transações pela rede
- Uso energético
- Uso de CPU

## Características de Construção

- Possui de 0 até n entradas | n `>=` 1
- Possui pelo menos 1 saída de informação
- Clareza para interpretação humana
- Finitude e Continuidade (Um algoritmo pode ser contínuo, mas não infinito)
- Eficaz
